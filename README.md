# Fetcher - Social Media Downloader Frontend

Website antarmuka (UI) untuk project Social Media Downloader API yang di-deploy ke Railway.

## Fitur
- **Premium Design**: Menggunakan glassmorphism dan animasi halus.
- **Dynamic API Config**: Bisa mengubah endpoint API langsung dari UI.
- **Responsive**: Nyaman digunakan di HP maupun Desktop.
- **Format Lengkap**: Menampilkan berbagai pilihan resolusi video dan kualitas audio.

## Cara Menggunakan
1.  Buka `index.html` di browser.
2.  Deploy API Downloader ke Railway (dari folder tetangga).
3.  Copy URL dari Railway (e.g., `https://api-xxx.up.railway.app`).
4.  Paste URL tersebut ke kolom konfigurasi API di bagian bawah website Fetcher.
5.  Masukkan link TikTok/IG/YT dan klik **Ambil Media**.

## Teknologi
- HTML5 & CSS3 (Vanilla)
- Modern JavaScript (Fetch API)
- FontAwesome Icons
- Google Fonts (Outfit)
